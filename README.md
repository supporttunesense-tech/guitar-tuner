# Тюнер для гитары (Android)

Простой тюнер: открыл, дёрнул струну — стрелка плавно показывает, подтянуть или ослабить.

## Что умеет
- **Гитара** — сам определяет, какая струна звучит; можно выбрать струну вручную.
- **8 строев**: стандартный, Drop D, полтона вниз, тон вниз, Drop C, Open G, Open D, DADGAD.
- **Любая нота** (хроматический режим) — укулеле, бас, голос, любой инструмент.
- **Защита от перетяга**: пока звучит одна струна, тюнер не «перепрыгивает» на соседнюю, а предупреждает красным, если струна ушла выше нормы больше чем на полтона.
- **«Похоже, звучит другая струна»** — если выбрана одна струна, а дёрнули другую.
- Отметки ✓ на настроенных струнах, «Все струны настроены 🎸».
- Подсказка «играй громче», индикатор микрофона.
- Камертон A4 от 415 до 466 Гц (по умолчанию 440).
- Экран не гаснет во время настройки; микрофон выключается, когда приложение свёрнуто.

## Как получить APK
Каждый push в `main` запускает сборку (вкладка **Actions**). Готовый `GuitarTuner.apk`
появляется в разделе **Releases** — его можно скачать прямо с телефона и установить.

## Как устроено
- `audio/PitchDetector.kt` — определение высоты звука (алгоритм YIN, точность < 1 цента).
- `audio/AudioEngine.kt` — чтение микрофона, ~20 измерений в секунду.
- `model/TunerLogic.kt` — сглаживание, отсев выбросов, выбор струны, предупреждения.
- `ui/` — экран на Jetpack Compose, шкала со стрелкой на пружинной анимации.
- `app/src/test` — тесты логики (запускаются при каждой сборке).
